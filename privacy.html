Privacy Policy – Shorts Uploader

Last updated: 9 November 2026

Shorts Uploader is a personal tool run on the channel owner's own computer. It is used only by the channel owner.

What data it accesses

  • Permission to upload videos and set thumbnails on the owner's YouTube channel (youtube.upload).
  • Read-only access to the owner's channel name and the status of uploaded videos (youtube.readonly).

How data is stored and shared

  • The sign-in token is stored only on the owner's own computer. No data is sent to any server other than Google's YouTube API.
  • No data is sold, shared with third parties, or used for advertising.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • This app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
